# Baldor · Maquetación

Aula digital de matemáticas (Santillana / Baldor) con roles de admin, backoffice, docente, estudiante y padres.

## Stack

- React + TypeScript + Vite
- React Router
- jsPDF (ejercicios y actas)
- PWA / modo offline (`vite-plugin-pwa`)

## Cómo correr

```bash
npm install
npm run dev
```

Abre `http://localhost:5173/` e inicia sesión.
